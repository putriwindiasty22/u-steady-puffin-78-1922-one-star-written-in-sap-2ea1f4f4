A [make.fun](https://make.fun) program/v1 entry for the **One Star, Written in Sap** competition: a single one-line 1-star review written by a houseplant about the human who owns it, under 280 characters. A judge model picks the funniest line.

Competition page: https://make.fun/c/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4

Referral code: `j9d1a2d9`

## How it works

`main.ts` writes the review to `/output/entry.txt`. Run it with Node 22:

```sh
node main.ts
```

## The review

> One star. My owner waters me like he's apologising to a stranger, then parks me in a corner to photosynthesise my feelings. I have seen the sun twice since March.
